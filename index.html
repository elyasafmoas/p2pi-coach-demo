DEMO — simulated coach, not financial advice

How this demo works

This is a front-end-only prototype. Every coach reply is scripted in a small JavaScript data file — there is no live model, no backend, and no API keys. The "thinking…" pause and word-by-word reveal are simulated to make it feel like a live LLM.

In production, the same experience would be powered by:

  • An LLM for natural, plain-language conversation.
  • RAG (retrieval-augmented generation) grounded in vetted, compliance-approved financial-education content — so answers stay accurate and on-brand.
  • A deterministic guardrail layer that classifies intent before the model responds and hard-blocks personal advice.

Guardrail principle: the AI never moves money and never advises. It teaches how things work; the decision always stays with the person.
